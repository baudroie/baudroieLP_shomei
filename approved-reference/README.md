## 素材の扱い
4枚は構図・背景表現の見本です。完成サイト用の画像素材ではありません。
ページ全体を画像で貼る、見本画像から写真や文字を切り出す、見本内の生成人物を実社員として扱うことは禁止です。
既存の原本素材とHTMLのテキストを使い、CSS/SVG等で構成してください。
特に人事・営業の見本はエンジニアの写真・コピーを使った比較用画像です。各職種へは背景の方向を適用します。
オレンジの正確な色は最新実装の確定値を優先します。
