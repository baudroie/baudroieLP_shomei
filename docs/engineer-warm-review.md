- overflowは装飾用コンテナで処理。ページ全体へのoverflow-x:hiddenは追加していない。

## 動き・操作

- FV見出しは行のマスク内で18px移動、560ms、開始差120ms。約680msで全文表示。
- 研修・キャリアの2見出しのみ10px/460ms。初回交差時だけ実行。
- FV・最終CTAの曲面のみPCで20px/650ms。表示後静止、スマホは背景移動なし。
- ボタンは矢印4px/200ms。経験別リンクは下矢印3pxと下線。非リンク画像への浮き上がりなし。
- 本文・CTAは常時表示。標準スクロールを維持。フォーカスは3px青枠。
- 実OSの「視差効果を減らす」をオンにして1440/390pxで確認。matchMedia=true、見出しopacity=1/transform=none、transition=0s。確認後オフへ復帰。
- `npm run build:engineer-preview` でエンジニア本文を事前HTML化。scriptタグを除いた `/qa-no-js/` でも7セクション、見出し、CTAの表示を確認。URL未設定のためJSなしでは設定待ちdialogは開かない。将来公開する場合は、この事前HTML化を配信ビルドにも組み込む必要がある。既存公開スクリプトは変更していない。
