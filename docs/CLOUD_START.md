# クラウド実装開始

このリポジトリは https://github.com/baudroie/baudroieLP_shomei です。ローカルPCのファイルを必要としません。

1. AGENTS.md と docs/IMPLEMENTATION_BRIEF.md を読み、reference/manifest.json のSHA256を検証する。4枚を実際に開く。
2. original-assets/README_review.txt と素材を棚卸しし、design-spec、content-corrections、asset-manifestを作る。
3. 既存実装・作業ブランチがないか調査。新規なら作業ブランチでReact + TypeScript + Viteを構築し、lockfileを保存する。
4. まとめ→営業→人事→エンジニアを実装。開発サーバーを0.0.0.0で待ち受ける。機密情報や不要なファイルを公開しない。
5. ブラウザ・フォントを整備し、1440px/DPR1と390px・768pxを検証。比較証拠にブラウザ版、DPR、viewport、日時、比較対象コミットを含める。
6. 比較と修正を繰り返す。各ページの構成35・文字20・素材20・色15・コピー導線10の参考配点で各96点を目標とするが、重大な差分があれば点数に関係なくneeds-fix。点数を合わせるために基準を緩めない。
7. ソース・QA証拠・進捗を作業ブランチ/PRに保存し、監督チャットから読めるようにする。共有プレビューが使えなければ利用者がlocalhostを開けるとは書かない。

## レビュー体制

実装担当はクラウドCodex。ユーザーの依頼元チャットがオーケストレーター兼レビュワー。進捗の根拠はコミット、PR、design-qa.md、docs/orchestrator-status.mdと比較画像です。自己申告のみで合格にしません。

各ラウンドでページ、箇所、期待、現状、原因、修正、証拠、状態を記録します。追加指示待ちで止まらず、自力で解消できる差分は修正します。
