# 原稿・最小補正の記録

原稿は `src/main.tsx` のページ別コンポーネント（Overview/Sales/HR/Engineer）に編集可能なHTMLとして保持。

|箇所|マスター|実装|理由|
|---|---|---|---|
|まとめ/成長|「2026年10月6日、公開買付けの成立を公表。」|公式サイトで最新状況を確認する案内|資料の時点情報を現在の確定事実としない。公式一次情報確認が完了するまで保留|
|まとめ/写真注記|イメージ（AI生成）|写真：公式メディアを参照|公式元写真を使用する箇所の出典を区別|
|営業/成長|「上司とは別に相談できるメンターも、入社後を支えます。」|同文|誤字補正不要。意味を維持|
|人事/支援|人事・営業・先輩エンジニア|同文|3者の連携を保持|
|エンジニア/機器・学び写真|写真イメージ|AI生成と明記|実在社員と誤認させない|

判読不能な文言を創作しない。LINEの正式URL、給与・選考フロー・架空実績・配属や昇進の保証は追加しない。人事の業務内容は承認された企画上の想定を含むとフッターに記載。経験者への訴求は対話の案内に留め、採用条件や配属確約にしない。
