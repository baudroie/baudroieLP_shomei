## 2026-10-19 写真注記の更新（旧方針より優先）

ユーザーの追加指示により、4ページの写真直下・フッターのAI生成／実社員ではない旨の写真注記を削除し、注記用の余白も整理する。別の長文注記へ置換しない。写真はビジュアルとして使い、生成人物に実社員の氏名・発言・経歴を付けない。altは画像内容を簡潔に記述し、実社員と断定しない。装飾画像の空altを維持する。

【マスター比較・修正ループ：必須】
ビルド成功やHTTP応答だけで完了にしない。4ページすべて実ブラウザで表示し、以下を自律的に繰り返す。

1. 画像ロード・フォントロードを待ち、ブラウザ幅1440 CSS px、ズーム100%、同一DPRで全ページと各セクションのスクリーンショットを取得する。ブラウザ・DPR・幅・取得時刻・コードの版を記録する。
2. マスターを幅1440pxに等比換算し、実装スクリーンショットと同じ縮尺で比較する。実装を歪ませたり縦寸法を強制伸縮して差を隠さない。
3. 全体比較と、ヒーロー／各セクション／フッターの拡大比較を行う。マスターと実装を必ず両方実見する。
4. 横並び比較画像、50%透過オーバーレイ、差分画像を保存する。全体の高さや位置のずれも評価し、セクション単位の位置合わせだけで隠さない。
5. 差分を「対象ページ・箇所・期待される見え方・現状・原因・修正内容・状態」で記録する。
6. 大きな構成差→幅と高さ→余白→画像とトリミング→書体と改行→細部の順に修正する。
7. 再撮影して差分が解消したか確認する。共通CSSを変更したら4ページに影響がないか再確認する。
8. 未修正の目立つ差がある限り、ユーザーに毎回「続けますか」と聞かず次の修正へ進む。

画像比較の数値は補助情報とし、数値だけで合格にしない。巨大な白背景で平均誤差を薄めない。点数を96点以上に調整する運用は禁止。
少なくともレイアウト、コピー、改行、主要画像、色、書体、セクション順、余白、導線の各項目を個別判定する。
目安として1440px換算で主要境界・要素位置は±4px程度、セクション高は±1%程度を狙う。ただしこれは再現精度の初期目安であり、目立つ差を許容する免罪符にしない。
アンチエイリアス等の描画差と、実際のレイアウト・素材差を分けて扱う。
完全なピクセル一致を達成していない場合に「完全再現」と断言しない。解決可能な差は修正し続け、素材不足・不明フォント等で解決不能なら該当範囲と必要素材を示す。無限に同じ修正を繰り返したり、勝手に基準を緩めたりしない。

【レビュー体制】
